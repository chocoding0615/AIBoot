# 공식 조회 원본 — 설치·검증 주의사항

상태: 2026-11-18 1차 구현 PR. **미병합·운영 미반영. 계약서 파일·DB C열은 추가 승인 예외로 확인했으며 승인 gid 매핑과 나머지 파일·보조 탭은 미확인.** 이 문서는 설치·조회 경계 설명이며 CURRENT.md·고정비 정책을 수정하거나 재정의하지 않는다. 기존 운영 사본은 그대로 유지한다.

## 조회와 식별

기존 config.json의 spreadsheetId / contractsSpreadsheetId / recurringSpreadsheetId / opsSpreadsheetId로 지정된 파일만 사용한다. 동일 이름 파일을 검색하거나 다른 ID로 대체하지 않는다. 요청 시작 시 파일 메타데이터의 정확한 파일명·탭명·gid를 확인하고 한 조회 패스 안에서 파일별 메타데이터를 한 번만 재사용한다. 다른 요청으로 메타데이터나 업무 값을 캐시하지 않는다.

| 역할 | 공식 파일 | 탭 | 직접 읽는 범위 |
|---|---|---|---|
| fixed | [MS] AD_관리비 내역 | JP매월 지출 | 보고·대화 B1:V37 / 연결현황 D14:D36 |
| contracts | [MS] AD_계약서 관리 | 계약서(DB) | C5:C, D5:D, E5:E, I5:I, N5:N, O5:O |
| licenses | [MS] AD_계약서 관리 | 프로그램(2026) | A5:D60 |
| recurring | [MS] 김현호 | 업무 | A2:E200, 업무ID 행 메타데이터 |
| welfare | [MS] AD_운영 관리 | 복지포인트 관리(2026) | A8:A, E8:E |
| 차량보험(contracts와 같은 gid) | [MS] AD_계약서 관리 | 계약서(DB) | 기존 C/E/I/Q 5:300 |

고정비는 기존 JP 집계값만 읽는다. 개별 DB·고정비 통합을 조회하거나 수식·집계 구조를 바꾸지 않는다. 계약서는 B열 노출 값을 읽거나 필터로 사용하지 않고 C 분류와 D/E/I/N/O 업무 필드를 받는다. O 계약 종료 제외, 종료일 D-7/30/60, N 자동연장 사실은 기존 판정을 유지한다. 검색 화면의 200행 한계 대신 각 허용 열의 끝까지 읽으므로 DB에만 존재한 행·B=FALSE 행이 새로 포함될 수 있다. 이는 공식 원본 변경에 따른 차이이며 실제 행·업무 원문은 PR에 싣지 않는다.

## 승인 gid 설치 전 필수 확인 — 미완료

새 코드에는 sourceSheetIds 승인 gid 매핑이 필요하다. **현재 운영 설정에는 이 매핑이 없다. 확인 없이 이 PR을 배포하면 조회가 차단되므로 바로 전환하지 않는다.** 기존 config·인증정보는 이번 작업에서 수정하지 않았다.

운영 보호 시간 밖이고 실행/발송/결과 불명 상태가 없는 때에만 기존 설정 파일 ID를 Google 메타데이터와 대조한다. 공식 파일명·각 탭의 gid를 확인하고 사용자가 승인한 숫자 gid만 로컬 설정에 넣는 별도 설치 절차를 승인받는다. 값은 GitHub·로그·PR에 올리지 않는다.

sourceSheetIds 키:
- fixed, contracts, licenses, recurring, welfare
- 기존 보조 점검이 필요한 경우 daily, history, master
- 차량보험은 contracts와 같은 계약서(DB) gid를 사용한다.
- gid 0도 유효한 숫자다. 미설정/비정수/다른 gid는 본문 조회 전에 확인 필요로 실패한다.
- 2027년 탭은 날짜만 보고 자동 선택하지 않는다. 공식 연도·새 gid 확인 및 사용자 승인 후 별도 코드·설정 전환 검증을 한다.

## 보조 탭과 숨김

AIBoot_데일리마감(daily)은 기존 고정비 확인 근거, 반복업무_처리이력(history)은 정기 업무 완료/보류 근거다. Master_Sheet(master)는 원본 등록 점검표이며 데이터를 찾는 라우팅 테이블이 아니다. 실제 원본은 기존 설정의 파일 ID와 위 공식 메타데이터로 찾는다.

사용자 추가 확정 기준: 승인된 파일 ID·정확한 파일명/탭명·승인 gid가 일치하면 숨김 여부와 관계없이 주/보조 탭을 읽는다. 숨김 속성을 조회 조건으로 사용하거나 이를 위해 별도 API를 호출하지 않는다. Master_Sheet 등록 점검, 데일리마감과 처리이력의 기존 완료 근거를 유지한다. 미승인 gid·ID 불일치·조회 실패이면 완료 여부 확인 필요로 둔다. 이력 부재와 조회 불가를 구분하고 미완료·미납으로 추정하지 않는다. 시트/로컬 이력을 쓰거나 자동 동기화하지 않는다. 숨김 자체는 더 이상 근거 차단 사유가 아니며, 실제 보조 탭의 승인 gid와 접근 가능 여부는 배포 전에 확인한다.

숨김 행·열은 필터링하지 않는다. 숨김 탭을 참조하는 기존 시트 수식도 바꾸지 않는다. 계약서와 라이센스를 함께 읽는 보고/연결현황 배치에서 한 탭이 미승인/ID 불일치이면 배치 전체를 차단하고 해당 분야들을 확인 필요로 처리한다. 다른 파일·검색 탭으로 우회하지 않는다.

## 호출 수·지연

합성 전체 소스 조회에서 Sheets/Chat 자료·메타데이터 API는 14회(파일 메타데이터 4회, Chat 2회 포함)다. 기존 읽기 경로 11회 대비 +3회다. recurring의 기존 파일 메타데이터 조회는 공통 검증 결과를 재사용한다. 파일당 여러 탭을 읽어도 메타데이터를 다시 요청하지 않는다.

보고 snapshot은 기존 JP+데일리마감 한 요청을 독립 요청으로 나누므로 숨김 여부와 관계없이 모두 승인된 경우 자료/메타데이터 호출은 기존보다 +4회다. 미승인 탭은 값 요청을 하지 않는다. 승인된 숨김 탭은 visible 탭과 동일한 요청 수로 읽는다. OAuth 갱신은 위 수에 포함하지 않으며, 대화/연결현황은 패스 안에서 동일 Sheets 클라이언트를 재사용한다. 새 코드의 실환경 지연은 미측정이다. 추가 지연은 메타데이터 왕복과 DB 행 수에 좌우되므로 15초 보장을 주장하지 않는다.

메타데이터 확인과 값 조회는 별개 API 요청이므로 그 사이 구조·이름·gid를 변경하는 동시 편집은 원자적으로 잠그지 못한다. 운영 중 구조 변경 시 조회 중지·다음 패스 재검증이 필요하다. 쓰기 잠금·새 스케줄러·지속 캐시는 추가하지 않는다.

## 검증과 복구

합성 데이터로 파일/탭/승인 gid 불일치, 승인된 숨김 주/보조 탭의 동일 결과·미승인 숨김 탭 차단, 메타데이터 실패, B TRUE/FALSE, O 종료, N 자동연장, 350행 DB, 잘못된 응답, 세 조회 경로의 동일 계약 사실, 호출 수를 검증한다. 실제 보고기 main 실행·발송 테스트는 금지한다. 기존 함수명과 원문/VM 추출 경계는 유지한다.

미병합 단계의 복구는 PR을 적용하지 않는 것이다. 향후 설치는 사용자 별도 승인·기존 설정 백업·이전 코드 복구 절차·보호 시간 밖 읽기 검증 후 진행하며 이 문서가 배포 권한을 부여하지 않는다. CURRENT.md, 고정비 규칙, 스케줄러, 웹훅, 원장, 인증정보, Google Sheets는 변경하지 않는다.

## C열 분류 재확인 — 2026-11-18

사용자가 정기 보고 보호 시간의 최소 읽기 예외를 승인했다. 작업/원장에 실행·발송 중 상태가 없음을 확인한 뒤 기존 계약서 파일의 메타데이터와 계약서(DB) C열·입력 규칙만 자료 API 2회로 읽었다. 총 2.462초, 공식 파일명·탭명·gid 존재 확인, 계약서(DB)는 visible이었다. 별도 C열 드롭다운 입력 규칙은 발견되지 않았다. 설정·원장·토큰·완료 상태·Sheets 인증파일 해시는 전후 동일했다.

관측한 분류 15개: 제조사 / 향료 개발 / 금형 제작 / 물류 / 광고비 / 수수료 / 시설관리 / 복리후생 / 지급임차료 / 임차보증금 / 시설비 / 건물 / 토지 / 차량운반구 / 보험료. 이 관측 목록을 코드의 인식 목록으로 사용한다. 공란·목록 밖 값은 category=null, categoryStatus=missing/unknown과 분류 확인 필요로 두고 원문 값은 출력하지 않는다. 이후 새 분류는 원본 확인 후 목록을 갱신하며 임의 유사 분류로 매핑하지 않는다. C열 분류는 종료일·O 계약 종료·N 자동연장·B 노출 필터를 대체하지 않는다.

차량보험은 기존처럼 C=보험료와 E의 차량보험 표시를 함께 확인한다. 보험료의 화재보험 등은 자동으로 차량보험이 되지 않으며, 다른 분류에 차량보험 문구가 있어도 차량보험 갱신 대상으로 바꾸지 않는다. 계약 만료 보고와 기존 C/E/I/Q 차량보험 갱신 판단의 기간·제외 규칙은 유지한다. 금액·계약 원문은 추가 출력하지 않는다.

C열을 기존 batchGet에 추가하므로 이번 보완의 추가 API 호출은 0회다. 합성 visible/전체-hidden 패스 모두 14회·메타데이터 4회로 동일함을 검증한다. C열 전송량은 늘지만 전체 신규 조회 경로의 실환경 지연은 미측정이다. 승인 예외는 위 계약서 C열 조회에 한정했으며 다른 파일·보조 탭 실데이터 성능 시험은 하지 않았다.

기존 설정의 계약서 파일 ID와 파일명·탭명은 대조했지만 sourceSheetIds 매핑은 여전히 없어서 승인 gid 일치까지는 확인할 수 없다. 다른 원본과 보조 탭의 실제 gid·읽기 가능 여부도 미확인이다. 운영 설정 변경 없이 초안 PR을 유지하며 병합·배포 전 별도 승인이 필요하다.

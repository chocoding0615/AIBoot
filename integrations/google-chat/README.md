# Google Chat Apps Script 시제품 (미배포/비주력)

- `Code.gs`는 별도로 작성된 **양방향 Chat 앱 및 웹훅 발송 실험 코드**다. 이 코드가 현재 Windows의 Codex·Antigravity 보고를 전송한다고 가정하면 안 된다.
- 실제 Chat 앱 배포·회사 계정 권한·스크립트 속성·정시 트리거·전체 고정비 회차 보고·발송 기록은 **검증/구현되지 않았다**. `previewMorningReport()`는 사용자 확인 기록만 요약하므로 최신 업무 보고를 충족하지 못한다.
- 사용자 확인에 따르면 2026-11-03 Claude Code로 기존 웹훅 테스트 발송 성공, 2026-11-04 Antigravity 오후 보고 메시지 수신. **이 저장소에는 그 로컬 실행기 설정/코드가 없다.**
- **새 Apps Script 생성·설정·실발송 지시를 하지 않는다.** 현재 우선순위는 기존 웹훅 오전/오후 보고의 수신과 내용 검증이다.
- 구현한 시제품 코드는 역사적 자료로 유지하되, 최신 운영 기준은 [CURRENT.md](../../CURRENT.md)만 따른다.
- 웹훅 URL, 토큰, 비밀번호 등 인증정보는 어떤 로그·GitHub 파일에도 출력하거나 저장하지 않는다.

# 확정 결정 기록 (기획)

## 제품 범위

- 경영지원 사용자 **1인**의 AI 업무 비서. 조직 전용 그룹웨어 재구축이나 개발 자체가 목적이 아님.
- 업무는 **반복 업무부터**, 이후 실제 사용 경험으로 일회성·예외성 업무 확장 여부 결정.
- 기존 업무별 Google Sheets는 유지. 통합된 **별도 업무 관리 시트**를 후속으로 검토하되 지금 당장 만들어 두지 않음.
- 업무 생성·완료 확정은 사용자 승인 전제. 일방적 AI 결정 방지.
- 첫 업무 실험은 **월 고정비 청구서 수신·금액 확인·시트 비교**.

## 데이터와 판단

- 청구서 수신 여부, 시트 기록 여부, 지출결의 **제출**, 결재 **승인**, 실제 **납부**는 **서로 다른 상태**.
- 관리비 시트 노란색은 **지출결의서 작성/제출 표시**. 승인·납부 의미 아님.
- 색이 없다는 이유만으로 미처리·미납 판단하지 않음. 포맷(셀 배경색) 자체의 도구 조회는 아직 성공 검증되지 않음.
- Gmail에서 메일이 검색되지 않으면 **'수신 확인 필요'**. 확정적으로 '미수신'이라고 단정하지 않음.
- 업체별 평소 청구서 도착 시점과 결제일 **두 기준**으로 확인 사항을 표시하되, 이력/예외 등 근거 없는 지연 확정 금지.
- 금액 불일치 시 **청구금액 / 시트금액 / 차액만 보고**. AI가 원인 조사나 시트 정정안을 임의 작성하지 않음.
- 처음에는 입력·수정 전 **사용자 승인**. 일정 기간 검증한 신뢰 가능한 업체에 한해 **업체별 개별 자동 입력** 허용 여부를 검토할 수 있음.
- 자동이체/카드 결제도 납부 완료를 뜻하지 않음. 실제 계좌 출금 또는 관련 증빙을 별도로 확인해야 할 수 있음.

## Google Chat 역할과 보고

- Google Chat은 1차 **보고를 받고 질문·지시·승인을 주고받는 양방향 창구**로 계획.
- 직원 Chat 스페이스 5개의 대화 내용 수집/분석은 **2단계**. 초기 범위에 넣지 않음.
- **오전 9:30** 근무일 전체 브리핑: 당일 할 일, 우선순위, 마감, 미처리·대기·확인 필요, 청구서 도착/차액.
- **오후 4:00** 근무일 간결한 요약: 완료·지연·대기·다음 날 과제 및 중요한 확인 사항.
- 메일이 도착할 때마다 개별 즉시 알림은 **필요 없음**. 정기 보고에 묶음.
- 주말·공휴일·종일 휴가에는 보고 생략, 반차일은 보고 유지. 휴가 복귀 후 누적 미처리/변경 사항을 포함.
- 지연된 업무는 기한을 원본대로 유지하고, 지연 사유·다음 확인 시점·진행 내역을 누적. 외부 응답/대표 승인 등 의존성 고려.
- 다우오피스는 전자결재/휴가 등 실제 업무 원천. 기술 연결 및 상태 확인 가능 범위는 **아직 검증 전**.

## 문서 해석 및 승인 범위

- 보고서에서 '확인 필요'를 '실패/미납/지연'과 구분.
- 오전·오후 보고 **형식과 실행 시각**은 결정되었지만 전송 수단의 API·봇·자동화 기술 방식은 검증 후 결정.
- 2026-10-30 선택: 보고 메시지 **실발송 없이 초안 생성(B)** 먼저 검증.
- 2026-10-30 선택: 첨부파일 처리 **C안** — 기본 ChatGPT 연결로 운영하고, 반복적으로 막히는 업체만 별도 로컬/도구 처리 검토.
- 이 문서는 사용자 결정이 있었던 것으로 확인된 사항만 반영. 세부 설정이 기록되지 않은 경우 **임의로 채워 넣지 않는다**.

## 2026-10-30 후속 실험에 따른 역할 변경 (최신 결정)

- 사용자 전달 실험 결론: **고정비 23건 중 무인 자동화 가능 3건, 자동화 어려움 20건**. 아직 업체별 분류 근거 및 3건의 명단은 이 대화에 제공되지 않았으므로 임의로 채우지 않는다.
- **완전 자동화 도입을 목표로 하지 않는다.** AIBoot의 주역할은 **AI 업무 비서**: 사용자 직접 수행 업무와 AI의 조회·정리·보고·입력 보조를 조합한다.
- 오전 09:30 보고는 전체 23건의 일정, 확인할 자료, 사용자 직접 처리 필요 항목, 확인 대기, 차액 등을 업무 중심으로 정리한다. 오후 16:00에는 사용자/시스템이 실제로 확인해준 완료·대기·지연, 다음 작업을 보고한다.
- **20건 역시 보고·추적 대상**이다. 자동화가 어려우므로 빠뜨리는 것이 아니라 사람 개입을 명확히 요청/기록한다.
- 사용자에게 인증·청구서 다운로드·카카오톡 파일 저장·전자결재·실제 결제 등 직접 해야 하는 작업을 요청한다. AI는 제공된 자료를 확인하고 가능한 업무를 보조하며 상태를 정리한다.
- 시트 쓰기나 업무 완료 확정은 기확정된 승인/실증 원칙을 유지한다. 실제 저장 후 재조회 성공 시에만 '입력 완료'라 보고한다.
- 과거 문서의 '자동 처리 후보'나 '사이트 1건 자동화 시도'는 **이 최신 역할 결정보다 우선하지 않는다**. 별도 추가 자동화 개발은 후속 효용 판단 시에만 선택한다.

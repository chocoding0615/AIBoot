### 표의 근거와 해석 주의

- 위 **사용기간/납부 규칙은 `시트내용` 탭의 3~30행** 중 대상 업체와 일치하는 항목을 연결한 것이다. 커피마켓어스는 본사·매장·양주 3행을 한 개 관리 항목으로 통합했다.
- `JP매월 지출` 탭 H14:H36의 '결제일'은 **일자만 기재된 운영용 단순 필드**다. `시트내용`의 익월/당월·기간 구분을 대체할 수 없다.
- 월말은 28/29/30/31일로 달라진다. '말일'을 매월 **30일**로 환산하지 않는다.
- 기간이 다음 달로 넘어가는 항목은 **기간 종료 월/납부 월/금액 기록 열**을 반드시 구분한다. 명시적 근거 없이 '10월 시트 열 = 10월 납부 대상'으로 해석하지 않는다.
- `시트내용`에 수유 수도요금은 24일~23일로 나와 있지만, 사용자 설명 및 다른 이력 탭에 **두 달에 한 번 결제**로 기재되어 있다. **격월 회차가 어느 달에 끝나는지**를 고지서로 확인하기 전에는 일자만으로 납부일을 확정하지 않는다.
- 양주 수도요금은 `시트내용` 비고에 **상황에 따라 일 수 변경**으로 기록되어 있어 고정된 사용 시작/종료일을 추정하지 않는다.
- **생각공장 2026년 9월 사용분은 사용자가 납부 완료로 확인**한 사례다. 납부일 도래 알림에 재등장시키지 말 것. 실제 자동 납부 확인 기능이 성공한 것은 아니다.
- **매장 안전관리자:** 확인 작업 제외가 사용자의 지시. 관리표 23개 목록에서는 유지.

## 2. AI비서가 보고서를 만드는 순서

1. 업체별 **회차 키** 생성: 업체 + 사용기간 시작/끝 + 청구 대상회차.
2. 회차의 청구서 수신 경로(Gmail/외부메일/카카오톡 파일/사이트) 확인.
3. 해당 회차의 실제 납부 예정일 계산. 휴일/이월 예외는 **별도 확인되지 않았으므로 추정 금지**.
4. 회차별 상태를 **서류 확보 / 금액 비교 / 지출결의 제출 표시 / 결재 승인 / 납부 확인**으로 별도 관리.
5. 자료가 없거나 주기가 불분명하면 **'회차 확인 필요'**, 사용자 직접 처리할 항목을 오전 보고에 배치.
6. 오후 보고에는 **당일 확인된 변경 사항만** 갱신. 사용자가 '완료'를 확인한 회차만 그 해당 상태로 표시. 다음 달 다른 회차를 함께 완료 처리하지 않음.
7. 기존 원본 시트 변경 및 Google Chat 실제 발송은 별도 승인/기술 검증 이후.

**사용자 검토 응답 반영**
1. 베네피아: **사용기간 당월 1일~말일, 익월 15일 납부** 확정. 예: **2026년 9월 1~30일 사용분 → 2026년 10월 15일 납부 예정**. 원본 규칙표의 익월 20일은 구정보.
2. 수유 수도요금: **1~2월 사용 → 3월 말일 / 3~4월 사용 → 5월 말일**처럼 달력상 **격월** 회차. **60일 고정 가산 금지**(달마다 28/29/30/31일 다름). 관리표의 20일 및 옛 24~23일 메모는 최신 확인된 격월 규칙보다 우선할 수 없음.
3. 이지화물: **2026년 10월까지만 사용, 최종 정리 완료**. 11월 이후 신규 청구·납부 업무 자동 생성 및 정기 보고의 활성 할 일에서 제외. 과거 회차/감사 이력은 유지. 원본 Google Sheets의 23개 행은 변경하지 않음.
4. 양주 수도요금: 사용기간은 **대체로 당월 말일 무렵~익월 말일 무렵**. 실제 첨부 고지서의 사용기간 **2026-08-29~09-28**, 인출예정일 **2026-11-02**. 따라서 전월/익월 말일이라는 단순 일괄 산식은 정확하지 않으며, **실제 고지서의 사용기간·출금예정일을 우선**한다. 다른 고지서의 날짜는 추정 금지. 이미지의 수용가·계좌·주소 등 식별값은 문서에 저장하지 않음.
5. 매장 안전관리자: **기존 처리 기준 그대로 유지**, 사용자 지시대로 청구서 확인 업무 제외, 원본 관리 항목은 유지.

- 30일과 '말일'이 혼용된 항목은 별도 규칙의 달력상 말일 표기를 우선하고, 시트의 30일은 그대로 납부 확정일로 오용하지 않는다.

# 이어서 작업할 때 읽는 맥락

## 프로젝트

AIBoot은 경영지원 사용자 1명을 위한 AI 업무 비서. 기존 Google Workspace와 업무 시트, 다우오피스를 존중하며 반복 업무부터 실증한다. 60여 차례에 걸쳐 운영 방식이 논의되었으므로 똑같은 질문을 반복하지 않는다.

## 확정

- Google Chat: 근무일 09:30 전체 보고, 16:00 요약 보고, 양방향 질문·지시·승인.
- 원본 업무 시트는 보존, 향후 통합 업무 시트를 별도로 검토.
- 업무 승인·상태 확정·원본 수정에 사람 승인 필요.
- 고정비 23항목 전부 사용자 담당.
- 공용 메일 청구서는 회사 Gmail로 전달됨.
- 노란색은 지출결의 제출 표시만 의미, 미표시도 무조건 미처리 아님.
- 첨부파일은 기존 ChatGPT 연결에서 처리 가능한 만큼만 운영. 반복 실패 업체만 별도 수단 검토.

## 실증

- 현재 대화에서 Google Sheets 23개 항목 직접 조회 성공.
- 회사 Gmail 청구서 표본 5건 테스트를 별도 대화에서 수행하고 사용자로부터 보고 받음.
- 센디 2026-09 금액 6,334,900원 일치.
- Excel/보안 HTML/PDF 4건 처리 미완료.
- 본 대화 Gmail 검색은 계정 연결 오류로 실패.
- Google Chat 양방향 및 정시 자동 실행 미검증.

## 진행 규칙

- **지금은 개발 단계가 아니다.** 추가 기능 제안보다 연결/업무 검증.
- 사용자에게 이미 답한 내용을 반복 질문하지 말 것.
- 한 번에 방향을 정하고 가능한 테스트는 직접 진행.
- 보낼 메시지와 원본 데이터 변경은 명시 승인이 필요.
- 이 문서는 축어록이 아닌 2026-10-30 기준 인계 요약본이며, 모든 과거 질문과 답변 원문을 완벽하게 복원한 것이 아니다.

## 다음 시작점

Google Chat이 업무용 양방향 창구로 가능한지 연결 수단과 권한부터 확인. 메시지 실제 전송 전에 별도 승인 필요.


## 가장 최근 확정된 전환 (2026-10-30)

사용자가 다른 대화에서 후속 실험을 실시해 **23건 중 무인 자동화 가능 3건 / 어려움 20건**이라는 결론을 전달했다. 이에 **AIBoot을 자동처리 봇이 아닌 AI비서 역할로 정리**하기로 했다.

- 사람: 카카오톡 파일 저장, 전화 인증, 외부 사이트 청구서 확보 등 직접 개입; 업무의 최종 판단·승인.
- AI비서: 모든 업무(23건)의 일정/자료/확인 필요/진행 상태를 보고, 사용자에게 직접 처리할 일을 요청하고, 받은 자료를 정리·금액 비교·승인된 입력 보조·완료 결과 보고.
- 오전/오후 보고는 '자동처리 내역'이 아니라 '전체 업무 진행 및 요청 사항'을 다룬다.
- 위 비율은 사용자 전달 결과; 3건의 상세 명단은 미기록. 임의로 유추하지 않는다.
- 최신 결정이 과거 '한 건 더 자동화하자' 논의보다 우선. 되묻지 말 것.


## 2026-10-30 오전·오후 보고 실제 데이터 검증 진척

회사 Google Sheets에서 금액뿐 아니라 **셀 배경색 읽기에 성공**. 10월 R열에 금액이 있는 항목 3건(커피마켓어스 84,150원 / 서브 D 창고 전기료 23,820원 / 서브 E 창고 전기료 2,530원), 그중 노란색 표시 2건(D/E). 9월 노란색 19건. 단순 표시 확인이며 결제·승인 증거 아님. 보고서는 아직 발송 전 시뮬레이션이고 진행상태 회신/Google Chat 실제 전송은 미검증.


## 2026-10-30 사용자 최신 회차 규칙 교정

- 이지화물: 10월 종료, 최종 정리 완료 → 이후 활성 업무 보고에서 제외(원본 시트/이력 보존).
- 베네피아 납부 관리일: 15일로 변경(옛 익월 20일 사용 금지).
- 수유 수도요금: 1~2월→3월 말일, 3~4월→5월 말일. **달력상 격월**이며 60일 고정 가산 금지.
- 양주 수도요금: 고지서에 적힌 실제 사용기간·인출예정일 우선. 예시 2026-08-29~09-28 사용 / 2026-11-02 인출예정.
- 매장 안전관리자: 기존 제외 기준 유지.
- 원본 23건은 보존하되 이지화물 종료 이후 활성 22건. 세부 내용과 잔여 검토 사항은 `docs/BILLING-CYCLES.md` 참조.

# AIBoot — 고정비 업체별 상세 규칙

> 현재 업무·보고 정책은 [CURRENT.md](../CURRENT.md)만을 따른다. 이 문서는 **업체별 사용기간·청구회차·납부 예정일·원본 접근 경로와 사용자 확정 예외** 참조용이다. 날짜는 예정일이고 실제 지급 완료의 증거가 아니다. 아래 표는 실행기와 연결현황이 직접 파싱하므로 열 구조를 바꾸지 않는다.

- [원본 JP매월 지출](https://docs.google.com/spreadsheets/d/1za_CvtiImh51W9J_YzmY146rf7FaQ2oKz-3eHq8wiIo/edit#gid=695174831): 원본 23건 유지, 2026-10 종료 이지화물 제외 **활성 22건**.
- 연노랑: 지출결의 작성·제출 표시. 결재 승인·실제 납부와 구분.
- 베네피아: 1일~말일 사용분 → 익월 **15일**. 과거 익월 20일 기준 적용 금지.
- 수유 수도요금: 1~2월/3~4월 등 달력상 격월 사용분 → 해당 기간 종료 익월 **말일**. 고정 60일 간격 금지.
- 양주 수도요금: 실제 고지서의 사용기간과 인출 예정일 우선. 예정일 ≠ 실제 출금 완료.
- 매장 안전관리자: 청구서 확인 작업만 제외. 다른 관리 업무까지 제외하지 않는다.
- 커피마켓어스·런치랩: 사용자가 해당 회차 전자결재 완료 확인(2026-11-04). 결재 완료로 분류하고 같은 단계 재요청 금지.
- 생각공장: 사용자가 관련 사용회차 납부 정상 완료 확인(2026-11-04). 같은 완료 회차를 불일치·미납으로 보고하지 않는다.
- 양주 전기료: 업체가 먼저 납부한 뒤 회사에 청구한다. 예정일 이전·당일은 청구서 수신·지출결의 작성 여부 확인으로만 보고하고, 예정일 다음 날(D+1)부터 일일 보고에서 제외한다. 청구서 미수신을 미작성·납부 지연으로 단정하지 않고, 수신 사실이 확인되기 전에는 수신을 추정하지 않는다.
- 매장 전기료: 5일~익월 4일은 사용기간 규칙이고 `매월 4일 직원 검침 요청` 업무가 아니다. 확인된 업무 지시 없이 임의로 추가하지 않는다.
- 금액 불일치: **동일 업체·동일 사용회차**의 청구액·원본액·차액·출처가 모두 있을 때만 보고.

## 안전한 적용

- 업체별 사용 시작/종료와 납부 예정일은 구분한다. 매월 30일 표기를 모든 달에 고정 적용하지 않는다.
- 미수신·미납·결재 지연·결제 완료는 근거 없이는 단정하지 않는다. 회사 Gmail 외부의 청구서/카카오톡/사이트 인증은 실제 접근이 확인되지 않으면 사용자 확인으로 남긴다.
- `CURRENT.md`의 분야 순서, 대분류 구분선, D-7/D-30/D-60, 중요 추천 1~3건을 이 문서의 예전 서술보다 우선한다.

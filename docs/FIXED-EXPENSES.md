- **Gmail** 표기만 회사 Gmail 조회 대상이다. 별도 이메일(양주 전기료), 카카오톡, 사이트 청구서를 Gmail 검색만으로 '미수신' 판정하지 않는다.
- **사람 개입 필요:** 베네피아의 휴대전화 번호 인증은 사용자에게 요청한다. **커피마켓어스와 매장 전기료** 등 카카오톡 명세서는 사용자가 직접 파일을 저장하고 AI에게 제공한다. AI는 카카오톡 계정에 직접 접근하거나 메시지를 수집하지 않는다. 제공된 파일에서 대상월·금액을 확인하고 원본 시트의 올바른 셀에 입력할 자료를 준비한다. **기존 정책대로 시트 실제 입력은 사용자 승인 후 실시**하고, 입력 결과를 재조회해 성공이 확인된 때에만 '입력 완료'로 보고한다.
- **사이트 확인 필요:** 푸딩, 런치랩(대안), 세금계산서 사이트, 쿠쿠, Spotify. 접근 권한·로그인·PDF 출력 자동화는 미검증. 로그인 비밀번호·인증번호를 GitHub에 기록하지 않는다.

6. 시트의 노란색(지출결의 제출 표시)과 실제 납부 완료는 별도 상태다.

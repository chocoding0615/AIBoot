## 메일 수신

- 공용 메일의 수신 정보는 원본 시트의 `수신메일` 필드에 기재되어 있으며, 실제 청구서가 사용자 회사 Gmail로 전달되도록 설정됨.
- 따라서 **Gmail로 청구되는 항목에 한해** 회사 Gmail에서 업체명/동의어/발신자/제목/본문/첨부파일로 매칭한다. 다른 이메일·카카오톡·별도 사이트 경로는 아래 표를 따른다.
- **수신메일 필드의 공용 메일 라벨을 Gmail 내부 라벨로 단정하지 않음.** 사용자의 설명상 공용 수신 계정이다.
- 기업 청구서 첨부 PDF 약 80%, Excel 약 20% (업무 경험에 따른 추정 비율).
- 암호화 문서가 일부 있으며 암호 규칙을 사용자에게서 확인했으나 실제 암호/사업자번호는 요청·추측·출력·저장하지 않음.

### 실행 원칙

- **Gmail** 표기만 회사 Gmail 조회 대상이다. 별도 이메일(양주 전기료), 카카오톡, 사이트 청구서를 Gmail 검색만으로 '미수신' 판정하지 않는다.
- **사람 개입 필요:** 베네피아의 휴대전화 번호 인증은 사용자에게 요청한다. **커피마켓어스와 매장 전기료** 등 카카오톡 명세서는 사용자가 직접 파일을 저장하고 AI에게 제공한다. AI는 카카오톡 계정에 직접 접근하거나 메시지를 수집하지 않는다. 제공된 파일에서 대상월·금액을 확인하고 원본 시트의 올바른 셀에 입력할 자료를 준비한다. **기존 정책대로 시트 실제 입력은 사용자 승인 후 실시**하고, 입력 결과를 재조회해 성공이 확인된 때에만 '입력 완료'로 보고한다.
- **사이트 확인 필요:** 푸딩, 런치랩(대안), 세금계산서 사이트, 쿠쿠, Spotify. 접근 권한·로그인·PDF 출력 자동화는 미검증. 로그인 비밀번호·인증번호를 GitHub에 기록하지 않는다.
- **양주 전기료:** 별도 메일의 구체적인 로그인/전달 경로는 아직 정해지지 않았으므로 별도 검증으로 남긴다.
- **매장 안전관리자:** 이번 **청구서 확인 워크플로우에서 제외**하되 원본 시트의 23개 관리 항목 중 하나로 유지한다. 사용자가 지시하지 않은 삭제·누락·지급중단을 해서는 안 된다.
- 청구서·정산서류 확보와 금액 비교, 지출결의 제출, 결재 승인, 실제 납부 확인은 별도의 상태로 관리한다.

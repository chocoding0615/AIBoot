# AIBoot — 경영지원 업무 누락 방지 AI 비서

**현재 기준:** [CURRENT.md](CURRENT.md) — 최신 확정 범위·오전/오후 Google Chat 업무보고 형식·참조 소스·추천 기준·검증 상태를 **한곳**에서 관리한다.

**고정비 회차 상세:** [docs/FIXED-EXPENSES-V1.md](docs/FIXED-EXPENSES-V1.md) — 23개 원본 항목별 규칙(이지화물 종료 후 활성 22개).

## 사용 목적

기존 회사 업무자료를 유지하면서 **평일 09:30·16:00 Google Chat으로 '내용 요약 및 추천 / 오늘 완료 / 오늘 남은 일 / 내일 업무'**를 간결하게 보고한다. 업무 대분류는 고정비·복지·계약서·라이센스·기타 순서로 통일한다. 상단 추천은 근거 있는 중요 1~3건을 관련 사항끼리 합친다.

참조: 기존 Google Sheets, Gmail, **회사 자체 업무 캘린더(Google Calendar 아님)**, 지정 Google Chat 스페이스 5개, 사용자 완료 확인. **소스 접근·배포·자동 발송은 각각 별도로 확인**해야 하며, 이 저장소에 코드가 있다고 작동 중인 것은 아니다.

## 저장소 구성

- `CURRENT.md` : **유일한 최신 운영 기준**
- `docs/FIXED-EXPENSES-V1.md` : 원본 업체별 상세 규칙 및 예외
- `integrations/google-chat/` : 별도의 미배포 Apps Script 시제품(현재 웹훅 실행기라고 가정 금지)

과거 중복·충돌 문서는 현행 경로에서 제거했으며 **Git 이력에서 복원 가능**하다. 새로운 프로젝트·검증표·자동화는 이 문서 정리로 생성하지 않는다.

## 보안

웹훅 URL·API 키·로그인 정보·개인정보·청구서 원문을 GitHub에 올리지 않는다. 승인 없이 원본 시트를 수정하거나 결재·납부를 실행하지 않는다.

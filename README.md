## 현재까지 확인한 내용

- 회사 Google Sheets 연결로 2026년 고정비 **23개 항목** 및 월별 금액 조회 성공.
- 별도 ChatGPT 대화의 회사 Gmail 연결에서 5개 청구서 표본 검증 결과를 사용자로부터 전달받음. **센디 2026년 9월 청구금액 6,334,900원**과 시트 값 일치(차액 0원).
- 다른 4건은 Excel MIME·보안 HTML·PDF 읽기 오류로 **금액 비교 불가**. 1/5 성공은 이 표본의 처리 결과이지 전체 자동화율이 아님.
- 이 대화에서는 회사 Gmail 연결이 반복적으로 계정 권한 오류를 반환. Google Chat 양방향 발송, 정시 자동 실행, 휴가·다우오피스 연계는 **미검증**.
- 오전·오후 업무보고는 **시트 기반 초안만 시뮬레이션**. 실제 완료·승인·납부 판정은 불가능.

## 운영 원칙

- 현재는 **읽기 전용 검증**. Gmail·Sheets·Chat의 원본 변경이나 메시지 발송은 승인 전 금지.
- 사용자 승인 없이 업무 생성·완료 확정·금액 수정·자동 이체 등 실행하지 않는다.
- 기존 프로젝트에서 결정한 내용을 반복 질문하지 않는다. 검증 결과로 생긴 **진짜 미결정**만 묻는다.
- 개인·회사 인증정보, 실청구서 원문, 암호, 전체 사업자등록번호는 이 저장소에 적지 않는다.
- 이 문서는 *원문 대화의 축어록이 아닌*, 현재 접근 가능한 확정사항과 검증 결과의 **요약 인계본**이다. 과거 1~60번 모든 질문·답변의 원문을 완전 복원했다는 의미는 아니다.

## 최신 방향 변경 — 2026-10-30

후속 실험 결과를 사용자가 전달함: **고정비 23개 항목 중 현 조건에서 자동화 가능 3건 / 자동화가 어려운 항목 20건**. 세부 3건의 업체 및 검증 기준은 아직 전달받지 않았으므로 지정하지 않음. 초기 5건 표본 결과와 별개의 후속 평가임.

따라서 **23건 완전 자동처리 목표를 내려놓고, 사람과 AI가 분업하는 'AI비서'로 역할 전환**한다. 사용자는 인증·사이트 접근·청구서 확보·직접 판단 등을 수행하고, AI는 오전/오후 전체 업무 현황 정리, 해야 할 일/요청 사항 전달, 제공된 자료의 금액·대상월 확인, 승인된 범위에서 입력 보조 및 결과 보고를 담당한다. 20건은 '업무 관리 제외'가 아니라 '무인 자동처리 불가/사람 개입 필요'다.

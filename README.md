## 이 저장소에서 지켜야 할 원칙

- **현재 기준 문서:** `CURRENT.md`. 고정비 업체별 기준: `docs/FIXED-EXPENSES-V1.md`. 설치·명령어는 각 구현 폴더의 README에서만 관리. 동일한 규칙을 여러 문서에 복제하지 않음.
- **원본 보호:** 기존 Google Sheets는 보고와 연결현황에서 읽기 전용. 연노랑은 지출결의 제출 표시이며 실제 지급 완료와 다름.
- **실행기 한 곳:** 현재 정기 발송은 Windows 로컬 실행기만 담당. Apps Script는 별도의 미배포 양방향 기록 시제품이며, 트리거를 켜면 중복 발송 위험이 있음.
- **화면의 '정상':** 해당 회차의 보고 포함 또는 제외 사유에 대한 점검 상태. 과거 청구서·납부 완료를 보증하는 값이 아님.
- **보안:** 웹훅 URL, OAuth 토큰, 로그인 정보, 사내 메시지/청구서 원문은 GitHub에 넣지 않음.
- **배포 구분:** GitHub main 병합 ≠ Windows 운영 PC의 코드 전환. 09:30/16:00 발송에 영향 주는 작업은 운영 경로와 스케줄러부터 확인.
